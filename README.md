# PCStats Rates Site

Отдельный сайт (не связан с существующим players.html/Railway-бэкендом):
- `/` — таблица курсов валют по серверам + время последнего обновления
- `/players.html` — ники игроков по серверу (кто сейчас в сети)

## Запуск локально

```
npm install
RATES_SECRET=твой-секрет node server.js
```

Откроется на `http://localhost:3000`.

## Деплой (Railway / Render / любой Node-хостинг)

1. Залей папку на GitHub.
2. На хостинге создай сервис из этого репозитория (Node, `npm start`).
3. Задай переменную окружения `RATES_SECRET` — любой длинный случайный
   секрет, **тот же самый** нужно будет вписать в PCStats.lua
   (в константу `RATES_API_KEY`, см. блок кода для скрипта).
4. После деплоя скопируй выданный хостингом URL (например
   `https://твой-сайт.up.railway.app`) — его нужно вставить в
   PCStats.lua в константу `RATES_API_BASE`.

## API

- `POST /api/rates` — header `X-Report-Key: <секрет>`, body
  `{ server, az, btc, eur, vc, asc }` — обновляет курсы сервера,
  время обновления проставляется на сервере автоматически.
- `GET /api/rates` — публично, отдаёт все сервера с курсами и
  временем последнего обновления.
- `POST /api/players` — header `X-Report-Key: <секрет>`, body
  `{ ownerKey, nick, server }` — отмечает игрока "в сети".
- `DELETE /api/players` — header `X-Report-Key: <секрет>`, body
  `{ ownerKey }` — убрать запись вручную (необязательно — записи и
  так пропадают из выдачи через 20 минут без обновления).
- `GET /api/players?server=Tucson` — публично, список игроков онлайн
  (опционально фильтр по серверу).

Данные хранятся в `data/rates.json` и `data/players.json` (простые
JSON-файлы, без базы данных — этого достаточно для такого объёма
данных). На некоторых хостингах файловая система эфемерна между
деплоями/рестартами — если курсы будут "слетать", напиши, заменю
хранилище на постоянное (например, тот же подход, что у
players.html-бэкенда).
